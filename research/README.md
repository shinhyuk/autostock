## 데이터
야후 파이낸스 1분봉, 2026-10-26 ~ 2026-11-20 (20거래일). SOXL 이 약 100달러에서 31달러로 떨어진
**변동성이 극단적인 구간**이라, 이 결과를 평상시 장에 그대로 기대하면 안 된다.

```bash
python3 research/fetch.py research/data        # 최근 30일 1분봉 받기 (SOXL, SOXS, NVDA, SOXX, QQQ)
python3 research/search.py research research/data research/results.json   # 전략 6종 격자 탐색
python3 research/replay.py . research research/data                        # 봇 엔진 재생 vs 백테스트
```

## 가정
- 자본 1000만원(=$7,143) 고정, 매일 새로 시작(복리 없음), 한 번에 한 종목 전액
- 수수료 편도 0.25%(한국투자증권 미국주식 온라인), 슬리피지 편도 0.03%
- 신호는 봉 종가, 체결은 다음 봉 시가. 손절·익절·추적 손절은 봉 고가·저가로 판정(같은 봉이면 손절 먼저)
- 정규장만. 마감 5분 전 청산

- 개장 범위 돌파는 범위를 5~10분으로 잡으면 마이너스, 20~30분이면 플러스. 개장 직후 10분은 속임수가 많았다.
- NVDA·SOXX 가 개장가 대비 같은 방향일 때만 진입하는 필터를 넣자, 앞 10일과 뒤 10일 모두 플러스인 조합이
  162개 중 93개 → 138개로 늘었다(파라미터에 덜 민감해짐).
- 고른 설정: 범위 20분, 손절 1.5%, 익절 10%, 추적 3%(수수료 이상 벌었을 때부터), 개장 120분까지 진입, 하루 2회.
  최고점이 아니라 각 값의 중앙 성과가 좋은 쪽으로 골랐다.

- 봇 엔진에 같은 20일을 재생하면 20일 모두 같은 종목·순서로 매매했다(재생은 1분 단위 시세라 손절이 약간 늦어 금액은 조금 작음).

### 개선안 (8개 짝에 공통으로 도움이 되는지로 판단)
| 변경 | 좋아진 짝 | SOXL 제외 합계 변화 |
|---|---|---|
| 진입 마감 120분 → 60분 | 6/8 | +33.2%p |
| 추적 손절 끄기 | 6/8 | +45.3%p |
| 손절을 개장 범위 중간값으로 | 6/8 | +24.7%p |
| 1분봉 2개 연속 돌파 확인 | 0/8 | -63.8%p |
| 하루 1회만 | 4/8 | -10.7%p |
| 정오 청산 | 3/8 | -20.5%p |
| 범위가 넓은 날 쉬기 | 3~4/8 | 효과 없음 |

세 가지를 모두 적용하면 8개 짝 합계 +40.5% → +112.4%, 앞뒤 기간 모두 이익인 짝 2 → 5개.
하지만 SOXL 하나만 보면 +36.8% → +26.8%, 이익인 날 12 → 7일로 나빠진다.
자금을 5개 짝(SOXL·TQQQ·TECL·SPXL·TNA)에 나누면: 지금 설정 +9.2% → 개선 설정 +18.1%, 최악의 날 -2.7%.
모두 같은 한 달(기술주 급락)이고 종목끼리 상관이 높아, 미래에도 같다고 보기는 어렵다.
